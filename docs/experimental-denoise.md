# 实验降噪：目前仅离线验证

**尚未接入实时录音，不能通过环境变量开启实时降噪。**
录音链路输入为 16 kHz，而当前模块及 RNNoise 后端工作在 48 kHz；重采样、录音 VAD 帧、停止时尾帧与延迟还需要单独集成验证。
生产录音路径没有调用该模块，不改变现有录音行为。

## 已落地的离线路径

48 kHz mono → 原有 90 Hz 高通 → 语音门控 AGC → 爆破音防护 → nnnoiseless → 延迟对齐后的干湿混合。

前两级是实验链，**必须显式选用**（`with_backend_and_mix_preprocessed`）；原链路
`with_backend_and_mix` 语义不变，供 A/B 对照。

- **语音门控 AGC**：把语音 RMS 归一化到约 -26 dBFS，增益限制 ±12/+18 dB，
  dB 域平滑（衰减 20 ms、提升 200 ms），静音时**冻结**增益，避免底噪被放大
  又缩回造成抽吸。目标电平不是"越小越好"：压得过低会放大 16-bit 量化噪声。
- **爆破音防护**：80 Hz 低通取低频带，用**均方能量比**（而非瞬时包络，
  后者会逐样本抖动导致检测反复开关）判定 20–60 ms 的低频脉冲；判定期间
  以 3 ms 起音混入 160 Hz 二阶高通，60 ms 释放。稳态 60 Hz 衰减约 -17 dB，
  正常元音不介入。
- 已知边界：没有前视，最前 2–3 ms 仍原样通过；**已削顶的样本不可恢复**，
  真正的解法是降低系统麦克风增益或加大拾音距离。

- nnnoiseless 输入乘 32768、输出除 32768，显式适配 16-bit PCM 幅度契约。
- 后端一帧（480 样本 / 10 ms）延迟，干路 FIFO 同步对齐；不是把当前干帧与上一帧湿路直接相加。
- 原 FSM 特征与阈值保留，混合为 `g·wet + (1-g)·dry`。
- 分块不改变结果；`finish_mix()` 推出尾帧并裁去填充，输出总样本数等于输入。
- 非有限输入置零；后端非有限输出会锁存到干路旁路，避免 NaN/Inf 传播。
- 这些是工程契约，不等于语音保真、轻声召回或识别 CER 已获得提升。

## 运行离线工具

输入必须为 **48 kHz 单声道 WAV**。准备一个新的输出路径，不要覆盖原录音：

```bash
cd src-tauri
cargo run --offline --example denoise_offline -- /path/to/input.wav /path/to/output.wav
```

处理后音频是 f32 / 48 kHz / mono WAV；CSV 遥测写 stdout，诊断写 stderr。
CPU 性能评估可另用 `--release`，但不要把 debug 构建的运行耗时当作发布版延迟。

## 原衰减测试为何失败

最初测试假定高幅度白噪声一定衰减至少 6 dB。它不是模型 API 的保证；真实多幅度探针显示结果强烈依赖噪声形态和幅度，原断言把过强的质量假设当成了接线契约。

主会话复跑 16 组探针：固定种子 1234，4 种幅度 × 4 种信号，每组 200 帧（2 秒），丢弃前 50 帧后计能量与平均 pvad。部分结果如下，负 dB 表示后端输出能量下降：

| 幅度 | 信号         | 输出/输入能量 | 平均 pvad |
| ---- | ------------ | ------------- | --------- |
| 0.02 | 白噪声       | -6.3 dB       | 0.252     |
| 0.05 | 带限平稳噪声 | -39.3 dB      | 0.245     |
| 0.20 | 白噪声       | -1.0 dB       | 0.660     |
| 0.50 | 白噪声       | -0.9 dB       | 0.729     |

这些是**合成信号上的裸后端结果**，不是最终 FSM 混合输出的效果，更不是中文识别准确率。高幅度宽带噪声被模型判为语音倾向，不能靠调低单测门槛冒充普遍降噪能力。

可复现命令：

```bash
cd src-tauri
cargo test --lib --offline probe_matrix -- --ignored --nocapture
cargo test --lib --offline audio_toolkit::denoise
```

质量实验保留在显式诊断探针中；常规测试另外覆盖有代表性的中幅度带限噪声、真实后端有限值、分块一致性、干湿对齐、尾帧守恒与故障旁路。
常规测试中的带限噪声衰减断言不代表所有输入都满足相同衰减。

## 后续验收

1. 接入带限 16↔48 kHz 重采样，并正确处理重采样器与 RNNoise 延迟。
2. 接回固定长度 VAD 帧，保证流式回调与最终保存音频一致；停止时不丢尾、不输出零填充。
3. 每段录音重新初始化状态，验证默认关闭时逐样本原样。
4. 在同一组真实中文录音上比较安静/噪声、普通音量/轻声及不同模型的 CER、术语召回、误替换与延迟。参见 [中文输入 A/B 评估](chinese-evaluation.md)。
