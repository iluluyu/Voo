## 三、本包包含的新特性

1. **词库解析修复 + 两步确认**：词库导入解析修复；设置页移除已导入词库需两步确认
   （`removeConfirm` / `removeConfirmYes`），快捷键侧 `lexicon_snapshot` 拒绝坏存档。
2. **/sil 清理**：Fun-ASR 输出标记 `/sil` `/nospeech` `/noise` 替换清理
   （`strip_funasr_markers`）：标记后紧跟 ASCII 字母数字（如用户听写 `/silence`）保留原文；
   两侧是汉字的替换空格删除；折叠连续空白。
3. **批处理连续语句跨度**：`pause_commit_runner` 连续缓冲 + 分段器 + 绝对区间切片记账；
   已提交边界之前的样本与连续静音超 3 s 的前缀可安全回收。
4. **电平调理按 sol 参数**：InputLeveler 按实验 sol 参数包络工作（提升 500 ms / 衰减 20 ms /
   不为凑目标做净衰减；SNR 迟滞 >10 dB 进入 / <6 dB 冻结；底噪未就绪≈2.3 s 期间精确单位增益）。
5. **分段 400ms 原始 VAD 触发**：录音 sink 分段参数含 400 ms 原始（未 hangover）VAD 触发路径。
6. **粘贴焦点绑定静默降级**：向聚焦应用粘贴时焦点绑定失败不再报错中断，静默降级到常规粘贴路径。
7. **LLM 后处理 prompt + 词表注入**：词表不进指令正文，作为带防注入护栏声明的独立
   `<vocabulary>` 数据字段附在草稿后；候选词条最多 16 条、总计 512 字符预算；
   空词表/无匹配时请求逐字节不变。

## 四、人工验收步骤（6 项）

> 通用：在 Windows 测试机安装本包（接受未签名 SmartScreen 提示），开启应用日志
> （stderr 或日志文件）。失败时除下列日志行外，一并记录：复述语句原文、预期 vs 实际输出文本、
> 时间点。

1. **安装与首次启动**
   - 操作：运行 `Voo_0.1.0_x64-setup.exe` 安装并启动，托盘图标出现，进入设置窗口。
   - 预期：安装无报错；启动后托盘常驻；模型/快捷键设置可打开。
   - 失败收集：安装器输出；应用日志启动段（含 manager 初始化、模型加载行）。

2. **词库导入 + 两步确认 + 热词纠错**
   - 操作：设置 → 导入一份含纯汉字词条（可含一条格式错误行）的词库；随后在词库列表尝试移除；
     再用快捷键说一句命中词库读音的句子。
   - 预期：错误行被拒并提示，好行照常导入；移除需第二次点击确认才生效；听写输出按词表
     “应写作”纠正。
   - 失败收集：应用日志中词库解析/规则解析（rule warn，每次重建仅一次、只含行号）与
     `lexicon snapshot` 相关行；导入文件本身。

3. **停顿分段 / 批处理长句跨度**
   - 操作：按住/连按听写，说 40 s+ 长内容，中途自然停顿 1 s 与 4 s 各几次；观察边听边出
     （pause-commit）与停止后整段批处理两种路径。
   - 预期：停顿处按时提交出字；连续说超长时在硬上限处强制切一刀；停说后整段结果连贯，
     无丢句/重复句；批处理长句与分段结果不互相截断。
   - 失败收集：日志中分段/提交相关行（binding id、`Starting async transcription task`），
    并记录每次停顿的大致时刻。

4. **/sil 等输出标记清理（Fun-ASR 系模型）**
   - 操作：选用 Fun-ASR 系模型，先说含明显停顿的中文（“今天天气…很好”），再故意听写
     英文 `slash silence` 一次。
   - 预期：输出不含 `/sil` `/noise` `/nospeech`，汉字间无多余空格；而听写出的
     `/silence` 拉丁文本原样保留。
   - 失败收集：该次识别的最终输出文本全文 + 日志中该次转码/后处理行（标记清理为纯函数无
     专属日志，需靠输出对比定位发生在哪层）。

5. **电平调理（sol 参数）与分段 400ms 原始 VAD 触发**
   - 操作：在安静环境先静默 ~3 s 再开始说话（正常音量，含几处很短的词间停顿），观察出字
     触发时机与音量条/输出一致性；再在略吵环境重复。
   - 预期：开头 ~2.3 s 底噪预热期内不出怪异放大；短停顿不误切段；400 ms 原始 VAD 命中能
     及时开段；不同底噪下音量稳定、无抽吸/过冲。
   - 失败收集：日志中录音 sink / VAD / level 相关行（含 VAD 帧判定与 level 冻结/进入状态），
    并注明环境（安静/吵）与时刻。

6. **粘贴焦点绑定静默降级 + LLM 后处理词表注入**
   - 操作：a) 正常聚焦一个可输入窗口听写一句；随后在焦点难以绑定的窗口（如部分管理员权限
     窗口/锁屏后）重复。b) 配置 LLM 后处理并保留词库中若干读音相近词条，说一段混含这些词
     与英文的内容；再把词库清空对比一次。
   - 预期：a) 两种窗口都能得到文本（降级路径静默成功，无报错弹窗）；b) LLM 输出按词表纠正
     写法、不编造内容、词表外行为与关闭一致；空词表时请求与无词表完全相同。
   - 失败收集：a) 粘贴/剪贴板相关日志行及目标窗口类型；b) LLM 请求/响应日志行（注意脱敏），
    以及两次（含词表/空词表）的输出对比。
